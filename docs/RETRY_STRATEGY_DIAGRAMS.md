## Data Flow Diagram

```
Input Data Flow:
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ Retry Context   │───►│ JNI Bridge      │───►│ Java Callbacks │
│ ├─ attemptNumber│    │ ├─ Thread attach│    │ ├─ shouldRetry()│
│ ├─ errorCode    │    │ ├─ Data convert │    │ ├─ getRetryDelay│
│ └─ operationType│    │ └─ Method invoke│    │ └─ Business     │
└─────────────────┘    └─────────────────┘    │   Logic         │
                                              └─────────────────┘

Output Data Flow:
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ Java Return     │───►│ JNI Bridge      │───►│ PIC Layer       │
│ Values          │    │ ├─ Convert bool │    │ ├─ shouldRetry  │
│ ├─ shouldRetry  │    │ ├─ Convert long │    │ ├─ retryDelayMs │
│ └─ retryDelayMs │    │ └─ Set output   │    │ └─ Execute      │
└─────────────────┘    │   parameters    │    │   Decision      │
                       └─────────────────┘    └─────────────────┘
```
